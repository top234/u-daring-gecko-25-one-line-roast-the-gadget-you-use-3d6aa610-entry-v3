## The roast

> My phone's battery saver kicks in at 5%, then burns its last 5% explaining how much it saved.

## Run locally

```sh
OUTPUT_DIR=/tmp/roast-v3-out node main.ts
cat /tmp/roast-v3-out/entry.txt
```

`main.ts` (Node 22, TypeScript, builtins only, no network, no dependencies)
writes exactly one roast line to `$OUTPUT_DIR/entry.txt`
(default `/output/entry.txt` when `OUTPUT_DIR` is unset).
